# C++ 이전 작업 Git 업로드

## 계획

1. 원격 main과 로컬 기준 커밋을 대조하고 변경 파일과 비밀 정보 후보를 확인한다.
2. Source, 이전 연결 목록, 작업 문서, 변경 Blueprint 19개, 프로젝트·빌드 설정만 커밋한다.
3. 사용자가 선택한 main으로 일반 push를 실행한다. 강제 push는 하지 않는다.
4. 원격 main의 커밋과 로컬 커밋이 같은지 확인한다.

## 범위와 검증 기준

UnreelMCP 플러그인, node_modules, AI 도구 설정·지식 저장소, 자동 생성 솔루션,
빌드 결과물과 Saved의 로그·백업은 이번 업로드에서 제외한다. 로컬 파일은 삭제하지 않는다.
게임 소스는 UnreelMCP에 의존하지 않는다. 프로젝트는 UE 5.8을 사용하며 설치 환경에 따른
에디터 플러그인 설정은 기존 작업 상태를 유지한다.

직전 클래스 분리 작업에서 Windows 11·UE 5.8.2의 Editor·게임 빌드,
93개 규칙 검사와 88개 화면 없는 맵 검사가 통과했다. 이번 업로드는 그 결과를 사용하며
배포본·새 컴퓨터에서의 실행이나 전체 플레이를 새로 검증한 것으로 간주하지 않는다.
원격 저장 확인은 push 결과와 원격 참조를 기준으로 하며 CI 통과를 의미하지 않는다.

지식 검토 범위는 current-project다. 이번에 main으로 올리는 선택은 이 업로드에 한정하며
앞으로의 기본 브랜치 규약으로 일반화하지 않는다. 별도 Hive 조회는 기존 통합 잠금 오류로 실패했다.
