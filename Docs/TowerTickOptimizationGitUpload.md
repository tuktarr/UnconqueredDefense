# 타워 Tick 최적화 GitHub 업로드 계획

## 목표

현재 작업 트리에서 공격 대상이 없을 때 타워 Tick을 끄는 변경만 분리해 GitHub에 올린다.

## 포함 범위

- 다섯 타워 Blueprint의 시작 Tick 비활성화 설정
- 첫 대상 진입 시 Tick 활성화, 마지막 대상 이탈 시 Tick 비활성화 공통 규칙
- 다섯 타워의 상태 전환 자동 검사
- 타워 Tick 최적화 결과 문서

## 제외 범위

- 몬스터, 라운드, 데이터 구조 이전 등 별도 작업
- Sphere 충돌 필터 검증 문서와 프로젝트 지식 저장소
- 빌드 산출물, Saved 측정 원본, 로컬 도구 설정

## 실행 순서와 확인 기준

1. 원격 `main`과 로컬 기준을 갱신하고 같은 출발점인지 확인한다.
2. Tick 최적화에 해당하는 소스 부분과 자산만 별도 스테이징한다.
3. 스테이징 차이와 비밀 정보 후보를 확인한다.
4. 이전 빌드·명령let 검증 결과를 확인하고 필요한 최소 검사를 다시 실행한다.
5. 별도 기능 브랜치에 커밋하고 강제 갱신 없이 원격에 올린다.
6. 제목 `[feat_Tower] Optimization`, 내용 `- Tower 공격 대상 Tick 제거`로 PR을 만든다.

## 안전 경계

- 기존 사용자 변경은 되돌리거나 삭제하지 않는다.
- `main`에 직접 push하거나 병합하지 않는다.
- 이번 업로드는 Windows 11과 Unreal Engine 5.8.2에서 확인한 범위만 증명한다.
